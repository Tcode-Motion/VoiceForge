# VoiceForge for Android

Companion app. The engines (RVC, Demucs, Kokoro) run on your
computer; this app is the studio interface on your phone.

1. On your computer: `voiceforge gui`
2. On the phone (same Wi-Fi): open VoiceForge, enter the computer
   address (for example http://192.168.1.5:8760), tap Connect.

An 8 GB RAM phone runs this shell comfortably; all heavy work stays
on the computer. Built by CI (see .github/workflows/release.yml);
the debug APK is attached to each GitHub release.
