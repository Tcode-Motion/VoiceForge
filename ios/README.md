# VoiceForge for iOS

Companion app. The engines run on your computer; this app is the
studio interface on your iPhone or iPad.

Build: open in Xcode after generating the project with XcodeGen
(`brew install xcodegen`, then `xcodegen generate`), or use the CI
build. The CI build is an unsigned simulator app. Installing on a
real device or the App Store needs your own Apple Developer
account and signing; the code is ready for it.
